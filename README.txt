AVA CREATIVE PORTFOLIO — GITHUB PAGES STARTER

FILES
- index.html: website content and page structure
- style.css: royal blue / yellow responsive design
- script.js: mobile navigation and footer year
- assets/: add your own logo and professional photo here

BEFORE PUBLISHING
1. Add your original AVA Creative logo as assets/ava-logo.png.
2. Add your professional portrait as assets/profile-photo.jpg.
3. In index.html, replace the Calendly placeholder URL:
   https://calendly.com/REPLACE-WITH-YOUR-USERNAME
4. Replace the LinkedIn and Facebook links with your real professional profile URLs.
5. Replace the two testimonial placeholders with genuine testimonials only.
6. Confirm certificate titles and add certificate images/links only for certificates you have earned.
7. Review every project description and remove anything you do not want public.
8. Do not upload client names, private messages, personal data, or confidential screenshots.

PUBLISH WITH GITHUB PAGES
1. Create a public repository named EXACTLY: YOUR-GITHUB-USERNAME.github.io
2. Upload index.html, style.css, script.js, and the assets folder (including your images).
3. Open repository Settings > Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select branch "main" and folder "/ (root)", then Save.
6. Wait for deployment. Your site will be:
   https://YOUR-GITHUB-USERNAME.github.io/

TIP
You can edit the website later by opening a file in GitHub, clicking the pencil icon, making changes, and committing them.
